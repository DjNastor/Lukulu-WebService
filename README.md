# Lukulu WebService

The website for Lukulu Web Designs, built with Vite, React, TypeScript, and Tailwind CSS.

## Development

Requires Node.js 24.x.

```bash
npm ci
npm run dev
npm run lint
npm run build
```

For Vercel use the Vite preset, `npm ci`, `npm run build`, and output directory `dist`.

Never commit Firebase service-account files, `.env` files, API keys, or other credentials.
